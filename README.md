# Plataforma de Automatización DevOps

> **📖 DOCUMENTACIÓN CENTRAL:** [docs/README.md](docs/README.md)

---

Este repositorio contiene la **infraestructura como código (IaC)** y los componentes de automatización para CI/CD, notificaciones y gestión de incidentes.

Implementa un flujo completo de **CI/CD** automatizado con:
- ✅ Jenkins como orquestador central (IaC con Terraform)
- ✅ Integración automática con GitHub (creación de ramas, webhooks)
- ✅ Despliegue a Lambda serverless
- ✅ Notificaciones en Teams
- ✅ Infraestructura 100% versionada en Git

# 🏗️ Componentes Principales

- Jenkins (orquestación CI/CD)
- Terraform (infraestructura)
- AWS Lambda + API Gateway (automatización y notificaciones)
- GitHub (webhooks y flujo de cambios)
- Jira + Teams (incidentes y comunicación)
